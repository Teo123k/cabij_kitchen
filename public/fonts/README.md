# PDF font

Noto Sans KR, distributed under SIL Open Font License 1.1 (see OFL.txt).
Source: https://github.com/notofonts/noto-cjk/tree/main/Sans/Variable/TTF/Subset
Original file: NotoSansKR-VF.ttf. The bundled TTF is a regular-weight (wght=400) static instance, generated with fontTools 4.68.0. It preserves Korean and Latin recipe names and is fetched only when a PDF is downloaded. jsPDF subsets the font in each generated document.
